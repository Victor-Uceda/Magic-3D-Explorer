# Magic 3D Explorer

Explorador interactivo en 3D para cartas de **Magic: The Gathering (MTG)** utilizando Three.js, React Three Fiber y la API pública de Scryfall.

---

## 🚀 Tecnologías

* **Frontend:** React 18, TypeScript, Vite, React Three Fiber, Three.js, Drei, Lucide Icons.
* **Backend:** Firebase Cloud Functions / Local Emulators.
* **Persistencia:** Cloud Firestore & Firebase Auth.
* **API Externa:** Scryfall REST API.

---

## 📦 Instalación y Desarrollo

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Ejecutar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Verificar tipado y compilación:**
   ```bash
   npm run lint
   npm run build
   ```
